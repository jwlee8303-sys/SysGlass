# Claude Code / Codex 사용량

메인 창에서 계정 사용 한도 대비 사용률(%)과 다음 초기화 시각을 확인합니다.
설정 → 표시 항목 → AI 사용량에서 서비스별 표시를 끌 수 있습니다.
사용 한도는 계정 전체 기준이며, 현재 프로젝트의 토큰 수나 결제 금액을 의미하지 않습니다.

## 앱에서 연결하기

SysGlass의 **설정 → AI 서비스 연결**에서 각 서비스의 연결 버튼을 누릅니다.
별도 명령을 입력하거나 설정 JSON을 편집할 필요가 없습니다.

- **Claude Code 연결:** 필요한 설정을 자동으로 적용합니다. 이후 Claude Code를 새로 열고
  평소처럼 사용하면 첫 응답 후 약 5초 내에 사용량이 표시됩니다.
- **Codex 연결:** 로그인 상태를 확인합니다. 이미 로그인했다면 바로 사용량을 표시하며,
  로그인이 필요하면 공식 로그인 화면을 브라우저로 엽니다. 로그인은 5분간 기다리며,
  앱의 **로그인 취소** 버튼이나 설정 창 닫기로 취소할 수 있습니다.
- CLI가 설치되지 않았다면 서비스 옆의 **설치 안내** 버튼으로 공식 설치 페이지를 열 수 있습니다.
  설치가 끝나면 SysGlass를 다시 열어 연결 버튼을 누르세요.

두 서비스 모두 **연결 해제** 버튼이 있습니다. Claude Code는 연결 전 상태줄 설정으로 복원하며,
Codex는 공유된 CLI 로그인을 유지하고 SysGlass의 사용량 조회와 표시만 중단합니다.

## Codex 동작

SysGlass는 PATH의 `codex.exe` 또는 `codex.cmd`를 찾아 공식 `codex app-server`의
`account/rateLimits/read`를 약 1분마다 호출합니다. PATH에 없으면 사용자 AppData의
`npm` 폴더도 확인합니다.
계정이 반환한 구간 길이(예: 5시간, 7일)를 표시합니다. CLI 버전이나 계정이 한도 데이터를
제공하지 않으면 안내 문구를 표시합니다. API 키 전용 로그인은 구독 한도를 제공하지 않을 수 있습니다.
대화 생성이나 모델 호출은 하지 않습니다. 조회 프로세스는 완료·실패·취소 시 종료합니다.

## Claude Code 동작

Claude Code 공식 statusLine이 전달하는 `rate_limits`를 사용합니다.
SysGlass는 인증 파일을 직접 읽지 않습니다. 연결 스크립트는 사용률·초기화 시각·수집 시각만
`%APPDATA%/SysGlass/claude-usage.json`에 저장합니다. 대화나 프롬프트는 저장하지 않습니다.

연결 버튼은 Claude 사용자 설정의 `statusLine`만 변경하고 나머지 설정 값은 유지합니다.
기본 경로는 `~/.claude/settings.json`이며 `CLAUDE_CONFIG_DIR`을 지정했다면 해당 폴더를 사용합니다.
스크립트는 `%APPDATA%/SysGlass`로 복사하므로 SysGlass 실행 폴더를 이동해도 연결이 유지됩니다.
기존 상태줄이 있다면 원래 명령에 같은 입력을 전달하고 원래 출력을 표시합니다.
Git Bash가 있으면 Git Bash를 사용하고, 없으면 PowerShell로 기존 명령을 실행합니다.
연결 전 상태줄만 별도로 보관하며 전체 Claude 설정이나 인증 정보를 복사하지 않습니다.
설정의 들여쓰기·주석은 JSON을 저장하면서 변경될 수 있습니다.

연결 해제 시 다른 설정 및 연결 후의 사용자 변경을 유지합니다. 사용자가 상태줄 명령 자체를
바꿨다면 이를 덮어쓰지 않습니다. 프로젝트별 상태줄이나 조직 정책이 사용자 설정보다
우선하는 환경에서는 수집이 제한될 수 있습니다.

`rate_limits`는 지원되는 구독/게이트웨이 계정에서 제공되며 각 구간이 없거나 null일 수 있습니다.
정보가 없으면 0%로 표시하지 않고 안내합니다. Claude Code가 응답하지 않는 동안에는 파일이
갱신되지 않으므로 이 방식은 실시간 서버 조회가 아닙니다. 여러 세션은 마지막으로 기록한
계정의 데이터를 표시합니다. 여러 계정을 병행할 때 계정별 합산은 지원하지 않습니다.

## 갱신 상태

- 마지막 수집 시각은 Windows의 현지 시간으로 표시합니다.
- 조회 실패 시 마지막 성공 값과 실패 사유를 함께 표시합니다.
- 수집 후 10분이 지나면 오래된 데이터임을 알립니다.
- 초기화 시각이 지나면 막대를 숨기고 `갱신 대기`로 표시합니다. 새 수집 없이 0%를 추정하지 않습니다.
- 표시를 끈 서비스는 다음 수집부터 조회를 중단합니다. 진행 중인 Codex 조회는 최대 20초 후 끝납니다.

## 검증

```powershell
dotnet build SysGlass.slnx
dotnet run --project tests/SysGlass.UsageChecks/SysGlass.UsageChecks.csproj
```

검증 프로젝트는 외부 테스트 패키지 없이 JSON 경계값, 초기화/오래된 데이터 표시,
가짜 app-server의 초기화·조회·오류·취소, 기존 로그인 재사용 및 브라우저 로그인 흐름,
statusLine 스크립트의 저장 필드 제한, 자동 연결·복원 및 PowerShell/Git Bash의 기존 출력 보존을 확인합니다.
실제 계정에 로그인하거나 모델을 호출하지 않습니다.
